## 2026-05-23 - Focus States and External Links
**Learning:** Interactive elements such as text inputs and navigation buttons require distinct keyboard focus states for accessibility (e.g., `focus-visible`, `focus`). Target blank links need `rel="noopener noreferrer"` and descriptive `aria-label` attributes.
**Action:** Always include `focus-visible` utility classes for custom buttons and `rel="noopener noreferrer"` alongside specific `aria-label` for external links.
